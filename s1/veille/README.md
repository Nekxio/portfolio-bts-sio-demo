# Veille informationnelle

Exemple fictif de dispositif à adapter :

- **Question :** comment améliorer la sécurité d’une application web débutante ?
- **Sources possibles :** documentation officielle des outils utilisés et publications d’organismes spécialisés, à sélectionner et justifier.
- **Collecte :** regrouper les sources choisies dans un lecteur de flux ou un espace de notes.
- **Rythme envisagé :** un court créneau chaque semaine, à ajuster selon sa disponibilité.
- **Tri :** conserver les informations pertinentes, vérifier leur date et leur source, puis rechercher un recoupement quand c’est utile.

Une note de veille personnelle précisera les liens consultés, la date, l’idée retenue et ce qu’elle change dans la pratique. Aucune consultation réelle n’est attestée dans cet exemple.
