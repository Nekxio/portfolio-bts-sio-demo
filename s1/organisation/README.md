# Organisation des apprentissages

Exemple fictif d’organisation personnelle : les notes de cours, les exercices, la veille et les preuves sont classés par thème. Les fichiers commencent par une date et un sujet, par exemple `2026-11-18-planification.md`.

## Retrouver une information

Pour retrouver une règle sur les dépendances, chercher « planification » dans les notes, puis suivre le lien vers l’exercice concerné. Une note réutilisable précise son sujet, sa date, une idée essentielle et un exemple.

## Sauvegarde

Prévoir une copie séparée des fichiers importants et vérifier qu’une copie peut être restaurée. La méthode exacte et le résultat de l’essai doivent être renseignés après une vérification réelle : aucun test de restauration n’est attesté ici.
